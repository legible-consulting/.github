# Security

If you find a leaked credential or a vulnerability in any Legible Consulting repository:

1. Use GitHub's private vulnerability reporting on that repository (**Security** tab →
   **Report a vulnerability**). Do not open a public issue.
2. If the repository has no Security tab, contact Jamie Nisbet through
   [jamienisbet.com](https://jamienisbet.com) with the repository name and the file or commit.

A confirmed leak is rotated the same day. You will hear back within two working days.
